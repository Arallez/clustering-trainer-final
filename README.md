# Электронное пособие по методам кластеризации с использованием онтологического подхода (Clustering Trainer)

Интеллектуальная образовательная веб-платформа для изучения алгоритмов машинного обучения (методов кластеризации). Проект разработан в рамках выпускной квалификационной работы.

Приложение решает проблему нехватки интерактивных обучающих ресурсов, объединяя сухую математическую теорию, наглядный графический симулятор и систему интеллектуальных рекомендаций, построенную на базе графа знаний (онтологии).

## Возможности системы

Разработанное электронное пособие включает в себя следующие функциональные модули:

- **Интерактивный симулятор**: пошаговая визуализация работы 12 алгоритмов кластеризации (K-Means, DBSCAN, иерархические методы и др.) с построением дендрограмм.
- **Среда выполнения кода (Sandbox)**: безопасная изолированная среда (Docker) для выполнения пользовательских Python-решений с автоматической проверкой и AST-анализом безопасности.
- **База знаний и граф понятий**: интерактивная визуализация OWL-онтологии предметной области с подбором релевантных научных статей из открытых источников (Semantic Scholar, Crossref).
- **Адаптивные рекомендации**: механизм построения индивидуальной траектории обучения. Система анализирует историю решенных задач, вычисляет уровень освоения (mastery) концептов и рекомендует логичные следующие шаги на основе жестких и мягких семантических связей онтологии. Основная логика маршрутизации реализована во `views.py`, а механизмы в `recommendations.py` служат резервным (fallback) вариантом.
- **Учебное тестирование**: преподавательский контур для создания групп, формирования тестов из банка вопросов и автопроверяемых заданий, а также ручной оценки развернутых ответов.

## Технологический стек

Система спроектирована по модели **гибридной архитектуры** (модульный монолит с "островковым" применением SPA-компонентов).

*   **Бэкенд:** Python 3.11, Django 4.2.x
*   **База данных:** PostgreSQL (реляционное хранение данных пользователей, материалов, истории попыток и материализованной онтологии).
*   **Работа с онтологией:** owlready2 (формат файла — OWL).
*   **Фронтенд:** HTML5/CSS3 (Grid, Flexbox), JavaScript. Для высокоинтерактивных зон (симулятор, редактор кода, граф знаний) используются **Vue.js 3**, **Plotly.js**, **D3.js** и **Monaco Editor**.
*   **Развертывание:** Docker, Docker Compose (для изоляции основного приложения, СУБД и контейнера-песочницы).

## Архитектура по приложениям (Django Apps)

Веб-приложение разделено на 6 основных логических модулей:

1.  `core` — базовые страницы, профиль пользователя, аутентификация и кастомная административная панель.
2.  `encyclopedia` — ядро интеллектуальной логики: материализация OWL-онтологии, расчет рекомендаций, маршрут обучения (Learning Path) и поиск научных статей.
3.  `materials` — хранение теоретических учебных материалов в формате Markdown и учет прогресса их изучения.
4.  `tasks` — практические задания (написание кода и выбор ответа), валидация синтаксиса и хранение попыток.
5.  `simulator` — вычисления для визуального тренажера алгоритмов и взаимодействие с фронтенд-библиотекой Plotly.js.
6.  `testing` — контур тестирования для преподавателя: управление группами, контрольные работы и ручная оценка.

*(Примечание: Запуск пользовательского кода из `tasks` осуществляется через механизм `sandbox`, концептуально и документально связанный с симулятором вычислений).*

## Запуск проекта локально (Docker Compose)

Проект полностью готов к развертыванию через Docker Compose. Для запуска полного контура (включая песочницу для выполнения Python-кода) используется профиль `sandbox`:

```bash
docker compose --profile sandbox up --build -d
```

Контейнер `web` при старте автоматически:
1. Применяет миграции БД.
2. Синхронизирует онтологию (`python manage.py sync_ontology`).
3. Загружает демонстрационный курс (`python manage.py load_test_course`).
4. Собирает статические файлы и запускает сервер.

Остановка окружения:
```bash
docker compose --profile sandbox down
```

## Документация проекта

Актуальные файлы технической документации хранятся в папке `docs/`:

*   [CORE.md](docs/CORE.md) — Ядро, аутентификация и архитектура базы.
*   [ENCYCLOPEDIA.md](docs/ENCYCLOPEDIA.md) — База знаний, онтология предметной области, маршруты и адаптивные рекомендации.
*   [MATERIALS.md](docs/MATERIALS.md) — Теоретические учебные материалы.
*   [SIMULATOR.md](docs/SIMULATOR.md) — Интерактивный симулятор алгоритмов и механизм песочницы (Sandbox) для проверки кода.
*   [TASKS.md](docs/TASKS.md) — Практические задания по программированию.
*   [TESTING.md](docs/TESTING.md) — Учебные тесты (контур преподавателя) и системное функциональное тестирование проекта.

> **Важно:** Все изменения учебных модулей, добавление концептов в граф знаний и редактирование теории производятся через административную панель (`/admin/`). Редактирование непосредственно OWL-файла требуется только при изменении структуры самой онтологии (добавлении новых типов связей или базовых алгоритмов).
